# AMretro برای اندروید — نسخهٔ آزمایشی 0.1.0-beta

این نسخه یک APK مستقل از نسخهٔ دسکتاپ است. بستهٔ منتشرشده برای **ARM64 (arm64-v8a)** و **اندروید ۷ / API 24 یا جدیدتر** ساخته شده است؛ نسخهٔ ۳۲ بیتی و x86 برای انتشار وجود ندارد. فایل بازی یا BIOS تجاری همراه آن نیست.

## نصب و شروع

1. [APK اندروید](https://github.com/Araz0-0dev/AMretro/releases/download/android-v0.1.0-beta/AMretro-Android-0.1.0-beta-arm64.apk) را دریافت و روی دستگاه سازگار باز کن. ممکن است لازم باشد به مرورگر یا فایل‌منیجر، اجازهٔ نصب برنامه از همان منبع را بدهی. این APK خارج از Google Play منتشر می‌شود و ممکن است Play Protect هشدار دهد.
2. در AMretro، از **افزودن بازی** یک فایل شخصی GB، GBC یا GBA، یا ZIP حاوی بازی‌های فقط یکی از این سه نوع را انتخاب کن. یا بازی منتشرشده در پنل را از **فروشگاه** نصب کن. نصب جدید، حتی برای فایل شخصی، برای بررسی فهرست BIOS به اینترنت نیاز دارد. فقط از فایل‌هایی استفاده کن که حق استفاده از آن‌ها را داری.
3. از **کتابخانه ← بازی** اجرا کن. برای بازی‌های GB/GBC/GBA هستهٔ mGBA همراه برنامه است و دستهٔ دوبعدی و چندلمسی روی تصویر بازی ظاهر می‌شود. دکمهٔ «بازگشت» جلسه را می‌بندد. کنترل فیزیکی دکمه‌های اصلی نیز پیاده‌سازی شده، اما دستهٔ فیزیکی هنوز آزمایش نشده است. تغییر چیدمان یا نگاشت دکمه‌ها در نسخهٔ اندروید هنوز پیاده‌سازی نشده است.
4. در صفحهٔ تروفی‌های هر بازی، فعالیت محلی یا اطلاعات RetroAchievements را ببین. تنظیمات توضیح بیشتری دربارهٔ RetroArch و تروفی‌ها دارد.

## BIOS، فایل و ذخیره

- قبل از نصب، تمام BIOSهای **منتشرشده برای همان کنسول در کاتالوگ** بررسی می‌شوند. فایل موجود دوباره دانلود نمی‌شود؛ اگر SHA-256 ثبت شده باشد بررسی می‌شود و در صورت ناسازگاری بازنویسی نمی‌شود. بدون SHA-256 اصالت فایل موجود قابل تأیید نیست. کاتالوگ فعلاً مفهوم BIOS اجباری/اختیاری و انتخاب منطقه ندارد، پس BIOSهای ناسازگار با مسیر یکسان را هم‌زمان منتشر نکن.
- برنامه BIOS منتشرنشده را پیدا یا نیاز واقعی هر هسته را به‌طور خودکار تشخیص نمی‌دهد. BIOS فشرده پشتیبانی نمی‌شود؛ در پنل فایل تکی منتشر کن. BIOS همراه APK نیست.
- برای بازی، فایل خام و ZIP پشتیبانی می‌شوند؛ **7z و RAR در اندروید پشتیبانی نمی‌شوند**. سقف دانلود و استخراج هر بسته یک گیگابایت است. اگر ZIP چند بازی سازگار داشته باشد، اولین فایل با پسوند پشتیبانی‌شده انتخاب می‌شود. لینک دانلود کاتالوگ باید مستقیم و HTTPS باشد. سقف آپلود هر فایل در پنل Cloudflare همچنان ۱٬۰۰۰٬۰۰۰ بایت است.
- دادهٔ کتابخانه، تروفی‌ها و ذخیرهٔ باتری بازی‌های داخلی روی همان دستگاه و در فضای خصوصی برنامه‌اند؛ همگام‌سازی، انتقال و Save State در این بتا وجود ندارد. حذف برنامه، دادهٔ خصوصی آن را پاک می‌کند. حذف یک بازی از داخل کتابخانه فایل ذخیره‌اش را نگه می‌دارد، اما در افزودن دوبارهٔ فایل شخصی، این ذخیره خودکار به شناسهٔ جدید وصل نمی‌شود.

## کنسول‌های دیگر و RetroArch

برای کنسول‌هایی غیر از GB/GBC/GBA، RetroArch و هستهٔ مناسب را جداگانه نصب کن و از منوی بازی، اجرای RetroArch را انتخاب کن. انتقال خودکار فایل‌ها به RetroArch در این بتا به **اندروید ۱۰ / API 29 یا جدیدتر** نیاز دارد. برنامه نسخه‌هایی از بازی و BIOS را در `Download/AMretro/` می‌سازد؛ مسیر System/BIOS را در RetroArch روی `Download/AMretro/System` قرار بده، دسترسی فایل را تنظیم کن و **Overlay لمسی را در خود RetroArch فعال کن**. این فایل‌های عمومی ممکن است پس از حذف AMretro باقی بمانند. مسیر هسته، سطح دسترسی و پذیرش intent با نسخه‌های مختلف RetroArch متفاوت است؛ این اتصال هنوز روی دستگاه واقعی بررسی نشده و ممکن است به تنظیم دستی نیاز داشته باشد.

## تروفی‌ها و RetroAchievements

- **تروفی‌های محلی و غیررسمی AMretro:** برنز پس از یک جلسه، نقره پس از ۵ دقیقه، طلا پس از ۳۰ دقیقه و پلاتینیوم پس از ۲ ساعت فعالیت همان بازی. زمان جلسهٔ RetroArch تنها با تأیید کاربر و به‌صورت تقریبی ثبت می‌شود. این آمار محلی، ضدتقلب یا دستاورد رسمی نیست و همگام نمی‌شود.
- **دستاوردهای واقعی RetroAchievements:** برای بازکردن آن‌ها باید بازی پشتیبانی‌شده را در RetroArch با Achievements فعال و حساب خودت اجرا کنی. در AMretro نام کاربری، Web API Key و شناسهٔ صفحهٔ بازی را وارد کن تا پیشرفت واقعی خوانده شود. تطبیق خودکار ROM و شناسه وجود ندارد. بازی داخلی mGBA این دستاوردها را ارزیابی یا باز نمی‌کند. برچسب برنز/نقره/طلا بر اساس امتیاز و «پلاتینیوم» پس از تکمیل همهٔ دستاوردهای دریافتی، **طبقه‌بندی نمایشی و غیررسمی AMretro** است، نه مدال رسمی RetroAchievements.
- Web API Key در Android Keystore رمزگذاری و در تنظیمات خصوصی ذخیره می‌شود و برای دریافت اطلاعات به RetroAchievements ارسال می‌شود. در تنظیمات برنامه می‌توان کلید را پاک کرد.

## بازسازی و امضا

به Android SDK Platform 35، Android Build Tools 35، NDK r27c، JDK و ابزارهای `zip` و `keytool` نیاز است. هستهٔ ARM64 mGBA و سورس منطبق آن تحت MPL-2.0 در این پوشه قرار دارند. برای تولید APK از ریشهٔ مخزن:

```sh
export ANDROID_SDK_ROOT=/path/to/android-sdk
export ANDROID_NDK_ROOT=/path/to/android-ndk-r27c
export AMRETRO_KEYSTORE=/private/path/amretro.p12
export AMRETRO_STOREPASS_FILE=/private/path/password.txt
android/scripts/build.sh
```

اسکریپت نام مستعار کلید `amretro` را استفاده می‌کند و با `apksigner` امضا را بررسی می‌کند. برای اینکه نسخه‌های بعدی بدون حذف برنامه نصب شوند باید با **همان کلید خصوصی** امضا شوند. کلید و رمز را جداگانه و امن پشتیبان بگیر؛ هرگز آن‌ها را در Git، فایل Release یا گفتگو منتشر نکن. APK منتشرشده با کلید مستقل AMretro امضا شده است، نه کلید Google Play.

### تست‌های قابل تکرار

تست جاوا به JDK 11 یا جدیدتر نیاز دارد:

```sh
mkdir -p /tmp/amretro-tests/classes
javac -encoding UTF-8 -d /tmp/amretro-tests/classes \
  android/src/com/amretro/mobile/FileOps.java \
  android/src/com/amretro/mobile/StereoResampler.java android/tests/FileOpsTest.java
java -cp /tmp/amretro-tests/classes com.amretro.mobile.FileOpsTest
```

برای تست رابط با bridge ساختگی، `playwright` و مرورگر Chromium آن را نصب کن و از ریشهٔ مخزن `node android/tests/ui-mock.cjs` را اجرا کن؛ مسیر خروجی عکس اختیاری است: `AMRETRO_TEST_SCREENSHOTS=/tmp/amretro-ui node android/tests/ui-mock.cjs`. تصاویر این تست، عکس دستگاه نیستند.

## وضعیت آزمون این بتا

- میزبان libretro با هستهٔ ساختگی برای تصویر، صدا، ورودی و ذخیرهٔ SRAM، و با هستهٔ واقعی **Linux x86_64** mGBA برای ۳۰۰ فریم آزموده شده است. تست جاوا برای مسیر امن، ZIP، SHA-256، HTTPS و resampling انجام شده است.
- رابط، افزودن فایل Game Boy از فایل‌گزین، بررسی فهرست BIOS زنده، نصب و استفادهٔ مجدد از یک فایل BIOS ساختگی، اجرای دمو، تغییر ظاهری دکمهٔ A هنگام لمس و ثبت زمان جلسه با **APK آزمایشی x86_64** روی شبیه‌ساز نرم‌افزاری Android 9 آزموده شده‌اند. این بستهٔ آزمایشی با APK ARM64 منتشرشده فرق دارد و شبیه‌ساز به‌علت نبود KVM کند است؛ افت صدای ناشی از underrun مشاهده شد.
- **APK نهایی ARM64 هنوز روی گوشی یا شبیه‌ساز ARM64، دستهٔ فیزیکی، RetroArch واقعی، همهٔ نسخه‌های اندروید و بازی‌های مختلف آزمایش نشده است.** این یک پیش‌انتشار آزمایشی است، نه تضمین سازگاری یا کارایی.

## مجوزهای اجزای ثالث

هستهٔ mGBA با مجوز [MPL-2.0](third_party/MPL-2.0-mGBA.txt) عرضه می‌شود؛ سورس متناظر در `third_party/mgba-source-9a36d6576.tar.gz` است. فونت Vazirmatn تحت [SIL OFL](third_party/OFL-Vazirmatn.txt) است. تصاویر رابط اولیه با bridge ساختگی تولید شده‌اند؛ عکس گیم‌پلی در صورت انتشار از دمو متن‌باز `printer.gb` پروژهٔ [gb-demos](https://github.com/joamag/gb-demos) با مجوز Apache-2.0 است.
